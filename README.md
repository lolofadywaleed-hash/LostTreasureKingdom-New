# Lost Treasure Kingdom

مشروع لعبة مغامرات ثلاثية الأبعاد في مرحلة التهيئة (Phase 0).

- المحرك: Godot 4.7.2 stable.
- الهدف المخطط: Android ARM64.
- مشهد التشغيل المؤقت: `res://scenes/main.tscn`.
- الدقة الأساسية: 1280×720.
- العارض المحدد حاليًا: Forward+.

يحتوي هذا الالتزام على هيكل مشروع فارغ ومشهد تشغيل مؤقت فقط؛ لم تُنفذ القائمة أو الحركة أو الشخصيات أو العالم بعد. لم تُنسخ ملفات أو أصول من أي مشروع سابق.

حالة تجهيز Android: Android SDK وقوالب تصدير Android غير متوفرة في بيئة التهيئة الحالية. لم يُنشأ APK في هذه المرحلة.
